# Juyeon Joe — GitHub Pages

기존 https://juyeonjoe.weebly.com/ 의 공개된 최신 페이지를 이전한 정적 사이트입니다.
원문 기준: 2026-09-20. 실제 게시 여부는 GitHub 설정에서 확인해야 합니다.

## 게시
1. GitHub에서 `사용자명.github.io` 이름의 저장소를 만듭니다. 기존 저장소가 있으면 덮어쓰기 전에 내용을 확인하세요.
2. 이 폴더 안의 파일을 저장소 최상위에 올립니다. `index.html`이 최상위에 있어야 합니다.
3. Settings → Pages → Build and deployment에서 `Deploy from a branch`를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 설정하고 Save를 누릅니다.
5. 배포 완료 후 `https://사용자명.github.io/`를 확인합니다.
일반 저장소에도 게시할 수 있습니다. 상대경로를 사용하므로 `/저장소명/`에서도 작동합니다.

## 수정
- `index.html`: 소개, 학력, 연구비, 연락처
- `my-work.html`: 논문, 발표, CV 링크
- `assets/`: 스타일, 타이핑 효과, 프로필 사진, CV PDF
- CV를 교체할 때 파일과 페이지의 업데이트 날짜를 함께 수정하세요.

## 이전 범위
최신 사이트의 Home과 My Work, 사진, CV를 포함했습니다. About은 현재 메뉴에서 사라져 별도 페이지를 만들지 않았습니다.
짙은 파란색 배너와 기존 내용을 유지하고, 모바일 레이아웃과 읽기 접근성을 보완했습니다.
Weebly 광고와 플랫폼 전용 추적 코드는 포함하지 않았습니다. 이메일은 표준 mailto 링크로 변환했습니다.
타이핑 효과는 한 번 재생되며 동작 줄이기 설정을 존중합니다.
기존 Weebly 사이트와 도메인은 수정하지 않았습니다. 기존 주소의 자동 리디렉션은 Weebly 쪽에서 별도로 설정해야 합니다.
